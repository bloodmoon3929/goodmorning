# 굿모닝 (굿즈 모으는 닝겐)

캐릭터 굿즈를 IP·캐릭터 단위로 모아 보고, 온라인 최저가와 근처 오프라인 매장 재고를 한 번에 확인하는 서비스의 프로토타입.

UST AI 응용을 위한 UX 설계 · 팀 에뚜리들 (김상우, 임상원, 전하린)

## 사용자 조사에서 나온 요구

| 조사 결과 | 반영할 기능 |
|---|---|
| 오프라인 매장 주 이용 6/10 | 매장 찾기 (리스트·지도), 재고 상태, 길찾기·전화 |
| 판매처·재고 확인 어려움 9/10 | 온라인/오프라인 배지, 몰별 가격 비교, 재고 확인 시각·출처 표시 |
| "한 캐릭터의 피규어, 키링, 인형을 한꺼번에" (인터뷰 B·C) | IP → 캐릭터 단위 분류 |
| "사이트를 여러 개 띄워 두고 비교하기 힘듦" (인터뷰 C) | 같은 상품을 묶은 온라인 가격 비교 |
| 사진 검색 후 다른 버전 선택 2/3 | 이미지·텍스트 임베딩 검색 + 버전(variant) 구분 |

이전 단계(중고거래 매물 추천) 사용자 조사 프로토타입: [etturideul](https://github.com/bloodmoon3929/etturideul)

## 기술 구성 (계획)

- API 서버: Rust
- AI 서버: Python, EmbeddingGemma 2 (이미지·텍스트 임베딩), pgvector 코사인 유사도
- 수집: 쇼핑 API (네이버 쇼핑·쿠팡 파트너스 등), Scrapy + Playwright 크롤링, 판매자 직접 등록, 사용자 제보
- DB: PostgreSQL

## 폴더

| `docs/` | 화면 구성, API 명세, DB 설계 |
