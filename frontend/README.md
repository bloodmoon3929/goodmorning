## 작성 규칙

- 화면마다 진입 경로, 구성 요소, 상태, 버튼·동작 표를 쓴다.
- 버튼 번호(①②③…)는 PPT 화면의 번호 표시와 같다.
- 화면별 백엔드 요소는 UI 확정 후 단계 3에서 적는다.

## 공통 요소

- 하단 탭 바: 홈 / 굿즈 탐색 / 매장 찾기 / 마이
- 상품 카드: 상품 이미지, IP·캐릭터, 상품명, 온라인 배지, 오프라인 배지, 찜(♡)

|온라인 배지|오프라인 배지|
|--|--|
|`온라인 4곳 · 최저 12,900원` (배송비 포함 총액)|`근처 2곳 재고`|

> 판매 경로가 없는 쪽 배지는 표시하지 않는다.

---

### 1. 홈

- 진입 경로: 앱 실행, 하단 탭 [홈]
- 구성 요소 (위에서 아래 순서)
  1. 상단 바: 굿모닝 로고, 알림 🔔
  2. 검색창: 텍스트 입력, 사진 검색 📷
  3. 판매 경로 필터: 전체 / 🌐 온라인 / 📍 오프라인
  4. 내 IP: 회원가입 때 고른 IP (캐릭터 사진 타일), 맨 끝에 [+ 추가]
  5. 내 주변 재고: 가까운 매장 2~3곳 카드 (매장 이름, 거리, 내 IP 굿즈 재고 수)
  6. 내 IP 신상품: 상품 카드 목록
  7. 하단 탭 바 (🏠 홈 / 🧸 굿즈 탐색 / 📍 매장 찾기 / 🙂 마이)
- 상태
  - 로딩: 각 영역 자리에 회색 상자 표시
  - 위치 권한 없음: 내 주변 재고 자리에 [위치 허용] / [지역 선택] 버튼
  - 오프라인 필터 선택 시: 내 주변 재고 영역을 맨 위로 올림

|번호|버튼·동작|결과|
|--|--|--|
|①|알림 🔔|알림 목록 (가격 하락, 재입고, 제보 처리 결과)|
|②|검색창에 입력 후 검색|검색 결과 화면으로 이동|
|③|사진 📷|사진 촬영·선택 → 사진 검색 결과 화면으로 이동|
|④|판매 경로 필터|홈의 상품·매장 목록을 선택한 경로 기준으로 바꿈|
|⑤|내 IP 타일 · [전체] · [+ 추가]|해당 IP 화면 / 굿즈 탐색 탭 / IP 목록 조정 화면|
|⑥|내 주변 매장 카드 · [지도]|매장 상세 / 매장 찾기 (지도 뷰)|
|⑦|상품 카드 · ♡|상품 상세 / 찜 추가·해제|
|⑧|하단 탭|홈 / 굿즈 탐색 / 매장 찾기 / 마이|

### 2. 굿즈 탐색

- 진입 경로: 하단 탭 [굿즈 탐색], 홈의 내 IP [전체]
- 구성 요소: 상단 제목, 검색창 (IP·캐릭터 이름과 별칭), 판매 경로 필터, 품목으로 보기, 내 IP 타일 (3열), [IP 목록 조정]
- 내 IP에는 회원가입 때 고른 IP만 보인다. IP 추가 요청은 IP 목록 조정 화면 안에 있다.

|번호|버튼·동작|결과|
|--|--|--|
|①|검색창|IP · 캐릭터 이름과 별칭으로 찾기 (먼작귀 → 치이카와)|
|②|판매 경로 필터|홈과 같은 필터|
|③|품목으로 보기|피규어 · 인형 · 키링 · 아크릴 · 프라모델 · 랜덤 목록으로 이동|
|④|내 IP 타일|IP 화면으로 이동 (캐릭터 선택 · 품목 필터)|
|⑤|IP 목록 조정|보일 IP 고르기 · 빼기, 없는 IP는 추가 요청|
